# Delivery milestones

## M0: platform proof and architecture decision

Small transparent-overlay probes on the real Ubuntu environment and the other target desktop backends. Demonstrate first-stroke capture, visible pass-through, activation, keyboard handoff, and safe withdrawal. Choose and pin the actual compatible stack. Resolve the GNOME route or explicitly name a limited-preview outcome.

## M1: one complete vertical slice

Startup Hidden -> activate Draw -> draw one stroke -> enter PassThrough -> click and type below visible ink -> hide -> show the ink. Connect actual platform events, the pure reducer, transparent rendering, recovery controls, and a minimal independent toolbar. No screenshot shortcut.

## M2: complete MVP annotation workflow

Pen/highlighter, basic shapes, object eraser, undo/redo/clear, selected-output/DPI correctness, explicit local vector files, validated settings/diagnostics, privacy audit, failure handling, benchmarks, and a native MVP matrix. Label any restricted preview accurately.

## M3: certified V1

Simultaneous outputs, hotplug/session lifecycle, text and editing, ink-only exports, accessibility, packages, and native release certification on every published environment. The product's full cross-platform target is not complete until promised GNOME behavior is verified.

## M4: optional presentation and capture features

Capture/freeze, screenshot composite export, board modes, fading laser, spotlight, and pressure input, each introduced through its own updated spec, capabilities, privacy rules, tests, and evidence.

No calendar estimates are assigned before the platform probes establish the actual engineering effort.
